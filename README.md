**Prism Harvest** — an original arena game of light and shadow, drawn entirely on a canvas with synthesized sound and no assets. You are a wisp drifting through a dark grove: gather the falling light motes, chain them to raise your combo multiplier, and reach 1,500 points to light the grove. Shade sentries hunt you from the walls — faster and more numerous the longer you last — and one touch costs a life of three. Dash (SPACE) makes you untouchable for a heartbeat; a rare golden mote blasts every sentry near it. Move with WASD, the arrow keys, or by holding the mouse; P pauses, M mutes.

The game is plain static files under `game/` (no build step, no network): `index.html` plus one script per job — `config.js` (tuning and palette), `audio.js` (WebAudio-synthesized sound), `input.js` (keyboard and pointer), `entities.js` (the wisp, motes, sentries, particles and the spawn director), `render.js` (arena, HUD and screens) and `game.js` (the state machine and rules). `main.ts` hands the entry in: it copies `game/` to the output directory, decodes the screenshots there from the base64 packed in `screenshots-data.ts` (regenerated by `pack-screenshots.mjs` from the local captures in `screenshots-src/`), and writes `dossier.json` with the kit's vendored library in `vendor/`.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 — or serve game/ with any static file server

# hand the entry in (what the grader runs):
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
